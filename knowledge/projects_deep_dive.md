
# Projet : Initiation au machine learning – Classification d’images

## Contexte
Projet : Initiation au machine learning – Classification d’images
Projet réalisé durant le semestre 6 de la licence MIASHS.  
L’objectif était de découvrir les bases du machine learning appliqué à la reconnaissance d’images.

## Problème traité
Mettre en place un modèle capable de reconnaître un type d’image à partir d’un jeu de données fourni.

## Stack technique
- Python (Jupyter Notebook)
- PyTorch

## Décisions techniques
Choix d’un réseau de neurones simple afin de comprendre les principes fondamentaux de l’apprentissage supervisé.  
Utilisation de PyTorch pour la définition du modèle et l’entraînement.

## Difficultés rencontrées
Compréhension du fonctionnement interne d’un réseau de neurones.  
Gestion de l’entraînement du modèle et interprétation des résultats.

## Résultats et apprentissages
Implémentation et entraînement d’un modèle de classification d’images.  
Compréhension des étapes clés d’un pipeline de machine learning : préparation des données, entraînement et évaluation du modèle.


# Projet : TER – Analyse des performances des entraîneurs de football

## Contexte
Projet : TER – Analyse des performances des entraîneurs de football
Travail de Recherche Encadré (TER) réalisé au semestre 6 de la licence MIASHS.  
Projet de groupe portant sur l’analyse de données sportives.

## Problème traité
Analyser et comparer les performances des entraîneurs de football dans les cinq grands championnats européens.

## Stack technique
- Python et R pour l’analyse
- Données issues de FBref et Transfermarkt
- GitHub, VS Code, RStudio

## Décisions techniques
Répartition des tâches au sein de l’équipe.  
Organisation du projet et planification des étapes d’analyse.  
Choix d’indicateurs pertinents pour évaluer les performances des entraîneurs.

## Difficultés rencontrées
Hétérogénéité des données issues de différentes sources.  
Nettoyage et structuration des données avant analyse.

## Résultats et apprentissages
Analyse comparative des performances des entraîneurs sur plusieurs saisons.  
Projet salué par les encadrants.  
Renforcement des compétences en abstraction, manipulation et analyse de données.

# Projet : Portfolio avec assistant IA

## Contexte
Portfolio avec assistant IA
Projet personnel visant à créer un portfolio technique intégrant un assistant conversationnel basé sur l’intelligence artificielle.

## Problème traité
Créer un frontend attractif et intégrer un assistant IA capable de répondre aux questions d’un recruteur.

## Stack technique
- HTML, CSS, JavaScript
- Tailwind CSS
- Netlify (serverless)
- LLM Gemini

## Décisions techniques
Choix d’une architecture serverless afin de conserver un site statique.  
Mise en place d’une API via Netlify Functions.  
Choix d’une architecture RAG pour fournir des réponses fiables à partir de données contrôlées.

## Difficultés rencontrées
Conception d’une interface utilisateur fonctionnelle et lisible.  
Création d’une API conforme à l’utilisation d’un modèle de langage.

## Résultats et apprentissages
Intégration d’une architecture IA complète dans un projet web.  
Compréhension des enjeux liés à l’utilisation d’un LLM dans une application réelle.



# Projet : Jeu 2D plateforme

## Contexte
Jeu 2D plateforme
Projet réalisé à Epitech dans un délai de deux semaines.

## Problème traité
Développer un jeu 2D de type plateforme intégrant des mécaniques de déplacement et de gravité.

## Stack technique
- Java
- JavaFX
- GitHub, VS Code

## Décisions techniques
Choix du genre plateforme afin de travailler sur les notions de physique et de gravité dans un jeu vidéo.

## Difficultés rencontrées
Implémentation de la gravité, des collisions et des déplacements du joueur.  
Résolution de bugs liés à la physique du jeu.

## Résultats et apprentissages
Développement d’un jeu 2D comprenant deux niveaux et des zones intermédiaires.  
Renforcement des compétences en programmation Java et en logique de jeu.




# Projet : Job Board – Application web

## Contexte
Job Board – Application web
Projet réalisé à Epitech dans un délai de deux semaines.

## Problème traité
Créer une application web complète avec un frontend, un backend et une base de données fictive.

## Stack technique
- HTML, CSS, JavaScript, SQL
- MySQL, Node.js, Sequelize
- GitHub, VS Code

## Décisions techniques
Choix de technologies simples et compatibles afin de comprendre l’architecture complète d’une application web.

## Difficultés rencontrées
Conception de l’architecture backend.  
Compréhension des rôles des routes, services, modèles et contrôleurs.

## Résultats et apprentissages
Application fonctionnelle avec des offres d’emploi fictives.  
Compréhension du lien entre frontend, backend et base de données.  
Première mise en pratique d’une architecture backend complète.
